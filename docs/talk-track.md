RubbleEcho — Three-Minute Talk Track



Minute 1 — The Problem (Pratikshya)



After a building collapse, much of the search area can be hidden beneath debris. Finding a place to investigate is difficult, and a person might only respond when something prompts them.



RubbleEcho demonstrates a rover concept that explores an area, stops, knocks, listens, and uses simulated confidence estimates to choose another location to check. The goal of this prototype is to explain that search process clearly through a website.



Minute 2 — Live Demo (Yuni)



Yuni will select Demo and narrate the map, rover position, probe locations, confidence estimates, and event list as the simulation runs.



The audience can follow how the simulated rover moves between probe locations and how the displayed estimates change during the demonstration.



Minute 3 — What Is Real and What Comes Later (Caden)



The website, API, mission controls, and telemetry connection are software components. The search results and confidence values are simulated.



A physical rover chassis, knocker, microphone, and vibration sensor could be considered for a future version, but they are not connected in this prototype.



Safety Closing



RubbleEcho is a simulation prototype. It does not locate real people and must not be used for a rescue decision.
